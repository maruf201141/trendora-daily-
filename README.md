# Trendora Daily — Premium Editorial Publication

> *“Stories that stay with you. Ideas that move you forward.”*

Trendora Daily is a modern, mobile-first editorial magazine built with React, TypeScript, Tailwind CSS, and a client-side advertising integration system.

---

## 🌟 Editorial Sections

1. **Emotional Stories**: Human narratives on memory, family archives, loss, and quiet perseverance.
2. **Lifestyle & Wellbeing**: Evidence-informed micro-habits, cognitive rest, and morning clarity.
3. **Technology & AI**: Demystifying artificial intelligence, prompt engineering blueprints, and computing tips.
4. **Digital Skills**: Practical filing architectures (PARA method), information hygiene, and productivity.
5. **Online Safety**: Pragmatic cybersecurity routines, password manager best practices, passkeys, and privacy defense.

## 🚀 Key Features

- **Editorial Reading Experience**: Generous typography (Playfair Display, Plus Jakarta Sans, Lora), drop caps, balanced pull quotes, key takeaway summaries, and table of contents.
- **Search & Archive Filtering**: Instant multi-field search across titles, excerpts, tags, authors, and full text, with category segmented controls and URL query synchronization.
- **Official Contact Integration**:
  - Dedicated Contact page (`/contact`) with direct cards for the Official Facebook Page and primary email.
  - Category-specific email dispatch triggers (General feedback, Article corrections, Editorial suggestions, Advertising/partnerships, Privacy enquiries).
  - One-click copy email button with instant visual feedback.
  - Professional "Connect With Us" footer section with accessible icons and links.
- **Client-Side Advertising Architecture**:
  - All 10 owner-supplied ad scripts (Providers A through J) preserved with exact keys, dimensions, and URLs.
  - Safe sandboxed iframe isolation for HighRevenueFormat `atOptions` global configurations.
  - Pre-mounted container guarantees for ProfitableRate native units (`#container-c33b6c16e929619d5d484c3b93631e54`).
  - No accidental ad clicks, fake redirect loops, or disguised downloads.
  - Live in-app **Ad Console** allowing immediate toggling and diagnostic inspection.
- **Comprehensive Legal & Compliance Pages**:
  - About (Editorial charter, masthead, and bottom contact block)
  - Contact (Direct cards, categories, and transparent routing notice)
  - Privacy Policy (Detailed third-party ad network tracking, cookie controls, DAA/EDAA opt-outs)
  - Disclaimer (FTC advertising disclosures, medical/financial disclaimers)
  - Terms of Use (Intellectual property and acceptable use)
- **Advanced Dynamic SEO**:
  - Route-specific `<title>`, `<meta name="description">`, OpenGraph, and Twitter Cards.
  - Canonical link generation.
  - Schema.org structured data (`NewsArticle`, `WebSite`, `Organization`, and `BreadcrumbList`).
- **Responsive Mobile Layout**: Tested for 360px, 390px, 768px, 1024px, and 1440px viewports with zero horizontal overflow.

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Routing**: React Router DOM v7
- **Icons**: Lucide React
- **Typography**: Playfair Display + Plus Jakarta Sans + Lora

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run TypeScript check & lint
npm run lint

# Production build
npm run build
```
